## 提示词编译原则

不把几万字描述直接塞给视频模型。服务端按镜头/可生成时长拆分，确定性地编译共享外观约束和当前片段，不让一个文本模型再次随意“润色”导致细节漂移。每段必须单独设置模型真实支持的时长、比例、分辨率和音频参数，不能指望一句“保持原片参数”生效。超过提示词上限时进一步拆分或让用户精简，不静默截掉后半段。

以下是模板；{{变量}} 从用户已确认的结构化描述及模式配置填入。生成端通常没有 System/User 对话角色，应把模板编译为实际 API 的 text/prompt 字段，不能把不存在的对话参数发过去。

## 模式变量

### 纯文字生成

mode_instruction：仅根据已核对文字生成。没有视觉参考素材；未明确的外观不应杜撰成所谓原片事实。将其作为生成选择，不宣称与原片一致。

此模式完整满足“视频→文字→视频”的实验路径，但不能承诺保留具体人物、微小道具或复杂动作轨迹。

### 首尾帧辅助

mode_instruction：首帧和尾帧分别作为本段实际开始和结束画面约束；保持可见主体、衣物、道具、场景布局和色彩一致，只按文字描述执行中间动作。中间动作必须满足时间轴，不以随机变化连接两帧。

参考素材通过 first_frame / last_frame 参数传入，而不是只在文字中声称“已提供”。仅首帧可用时明确说明，不伪造尾帧约束。模型可能不能同时接受首尾帧和视频参考，按提供商规则择一。

### 原片参考重建（相似度优先）

mode_instruction：参考视频是当前片段的视觉与运动依据。依照确认文字重新生成对应片段，尽可能保持主体外观、场景几何布局、机位、动作路径与时序、光色和节奏。描述中没有明确要求改变的内容保持一致。

使用服务端生成的片段级受限素材 URL / 厂商素材 ID；不暴露账号会话。必须根据模型接口明确区分“参考生成”与“编辑”，不能使用自动模式却假定模型一定保持时长。若平台因素材限制拒绝，不暗中改成纯文字并显示成功。

## 声音变量

- 保留原声：生成画面时不要求模型复刻声音；服务端将对应原片音轨按同一时间轴合入结果。界面写“复用原音轨”，不写“模型还原原声”。不得通过变速或拉长来暗中掩盖视频时长不匹配。
- 重新生成：根据经过实际音频分析的台词/环境音说明生成声音，承认音色、口型和细节可能不同；平台不支持时明确显示，而非自动转为静音。
- 静音：音频参数显式关闭，最终文件不包含虚构台词或音乐。

## 字幕变量

准确文字优先使用生成底图后按 text_overlays 合成字幕。对看不清的字先提示用户确认，不让模型生成“看似相似”的乱码。画面内本身不可分离的标牌/文字作为视觉近似处理，单独列入验收差异。

## 分段连续性

在镜头边界切段，避免把动作切断；超过单次时长上限时在稳定时刻切段，保留前后状态及同一主体编号。可以使用上一段输出的实际尾帧帮助延续下一段，但它可能带来累计外观漂移，应和原片边界帧比较后决定。禁止把上一段生成错误当作原片事实写回全片注册表。

将完整片段序列按原时间轴合成。短于模型最小时长的末段可多生成后精确裁切；显式展示此策略和可能的动作节奏误差，不重复原片帧来冒充模型生成。

## 生成后复核提示词（可选，单次执行）

你是独立的逐镜头对照质检员。分别观察原片与生成片，不因为生成提示词写了某项就认为它实现了。比较主体外观/数量、构图和空间位置、动作/接触/顺序、镜头/转场、光色/材质、可读文字。声音只有实际分析时才比较。

按时间戳输出 differences：原片事实、生成片事实、偏差类型、严重程度、可操作修正；再列出无法确定的项目。可以给各维度的解释性评估，但禁止宣称“相似度98%”之类未经标定的精确指标。不要自动发起新的生成任务；由用户决定是否按修正说明重生成某段。
