# Android 0.1.1 修复记录

执行助手：Codex，2026-10-17。分析基线：GetVideo@a87a9ed，加本次未提交修改。本文记录本轮实测；原 `implementation.md` 的历史验收结论保留。

## 原因与修改

- 访客和平台授权：手机崩溃栈指向 `PlatformAccountPanel` 在服务器地址初始为空时构造 Retrofit。先验证配置，再创建客户端；未配置或无效时提供设置入口。去掉授权页嵌套的同向滚动容器。
- 服务器：原默认 `10.0.2.2:8900` 是模拟器地址。TX 上 `getvideo-api` / `getvideo-worker` 未运行，也没有独立 nginx 入口。新版默认未配置服务器，旧模拟器默认值迁移为空；自定义地址保留，不接入 GetAudio。手机直提取继续可用，账号、授权和同步需另行部署 HTTPS 服务。
- 测试连接：健康和账号检查合计最多 10 秒，取消会终止网络请求，连接期间可以关闭。网络截止不包住设置提交；提交后不可取消地完成账号可见范围和队列协调。
- 播放：默认库内预览，完整显示原比例；主动点全屏，横视频横向、竖视频竖向，收起和返回保持共享播放会话。旋转时重新设置全屏窗口尺寸。
- 抖音水印：两个实际作品的分享页 `play_addr` 都为 `aweme.snssdk.com/aweme/v1/playwm/`。在已识别的抖音域名及精确路径上换取对应 `/play/`；保留作品及查询参数，不修改任意第三方 URL。播放流优先于 `download_addr` 备用源。此策略获取平台原有播放源，不做裁切、模糊或重绘；作品自身的文字和标志仍保留，也不保证每个作品都有无水印源。

## 边界

两个用户样本均为横屏视频；竖屏布局策略已实现，但本轮没有新增竖屏平台作品作联网验收。其他作品、平台登录权限、地区和风控仍可能影响下载。未向 GitHub 推送，未写入飞书，未部署线上服务器。
